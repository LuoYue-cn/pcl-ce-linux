# PCL CE Linux 移植版

[下載最新版本](https://github.com/LuoYue-cn/pcl-ce-linux/releases/latest) |
[上游專案](https://github.com/PCL-Community/PCL-CE) |
[問題回報](https://github.com/LuoYue-cn/pcl-ce-linux/issues)

</div>

本倉庫是 [PCL CE](https://github.com/PCL-Community/PCL-CE) 的 **Linux 移植版**，
基於社群的 Avalonia 遷移工作（[PCL-CavE](https://github.com/PCL-Community/PCL-CavE)），
提供 Debian / Ubuntu 安裝包。

> 本專案為第三方修改版，與龙腾猫跃及 PCL-Community 均無隸屬關係。

## 安裝

```bash
sudo apt install ./pcl-ce_<版本>_amd64.deb
pcl-ce
```
